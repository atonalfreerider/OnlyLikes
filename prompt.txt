This is a browser extension for Chrome/Firefox called OnlyLikes. OnlyLikes performs the following functions as a browser extension:
1 - the User navigates to a social media post (ie Original Post aka "OP") on popular social media platforms like Facebook, HackerNews, Instagram, Reddit, TikTok, X/Twitter, YouTube
2 - OnlyLikes scrapes the Document Object Model on these sites and determines:
    - the username of the logged in User
    - if the OP Author is the User, or the Author of the OP is someone else
    - the comment tree underneath OP, and any comments submitted by User within this tree
3 - before the page contents are displayed in the browser, any response anywhere to anything that was submitted by User is hidden. This includes:
    - all comments under the OP if it was authored by User
    - any reply to any comment that is made by User anywhere in the comment tree
    - any comment that mentions user by their @username anywhere in the comment tree
4 - once these comments have been hidden, only these comments are submitted to the in-browser sentiment analysis tool, that evaluates each comment one-by-one:
    - if the sentiment score is greater than the threshold -> the comment is unhidden
    - else the comment remains hidden

The OnlyLikes plugin has one setting for User input, which is the sentiment threshold.
